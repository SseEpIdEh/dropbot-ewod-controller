# DropBot EWOD Controller

A browser-based control interface for DropBot and PCB-based EWOD digital microfluidics.

## Current Status

The current prototype includes a local Flask web interface with clickable test electrodes.

The project is being developed toward:

- Interactive EWOD electrode visualization
- Electrode-to-DropBot channel mapping
- Protocol creation and execution
- DropBot hardware control
- Camera-based droplet detection
- Closed-loop droplet control
- Future AI-assisted experiment automation

## Hardware Tested

- DropBot hardware version 3.6
- DropBot software/firmware version 1.73.6
- Apple Silicon MacBook

## Current Interface

Run:

python app.py

Then open:

http://127.0.0.1:5000

## Development Status

The current interface is for software development and does not yet actuate physical EWOD electrodes.
