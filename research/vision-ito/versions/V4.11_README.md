# EWOD Vision V4.11 — electrode-aware ITO diagnosis

**Experimental prototype; read-only; no actuation; not a validated droplet detector.**

## Motivation
The V4.10 baseline measures full-resolution changes between a saved empty ITO image and the live image. Repositioning ITO changes reflections and apparent electrode edges. Restricting the rectangular ROI reduces some false detections but excludes useful electrodes, including the large bottom electrode (channel 33).

## Experimental approach
- Project the saved 8-point magenta calibration and SVG electrode polygons into camera coordinates.
- Search for candidates **on and near** the physical electrode network (all reservoirs, transport electrodes, and channel 33) rather than solely in a rectangular ROI.
- Use DropBot channel numbers from electrode SVG metadata for tentative labels, not presumed droplet identities.
- Allow up to four **genuinely empty** images recorded with ITO installed at separate glass-placement IDs; a multi-reference comparison can suppress known repositioning artifacts.
- Include small image-translation correction, connected-region candidate filtering, limited temporal persistence, and read-only diagnostic exports.
- V4.11 does **not** send actuation commands or overwrite legacy V4.7–V4.10 calibration/reference state.

## Observed limitations and results (29 October 2026)
During an empty-chip test with one reference and fixed glass, the UI reported ~138 changed electrode-neighborhood pixels, zero tentative regions and zero stable candidates. After lifting and replacing the still-empty ITO glass, the UI reported ~11,453 changed pixels and 6 false stable candidates. Three empty references could give zero candidates when the current placement matched a captured reference; an unseen placement still produced 1,724 changed pixels, 14 tentative regions, and **9 false stable candidates**. These observations are individual experiments, not accuracy estimates, and show that multi-reference lookup alone does not solve held-out glass repositioning.

## Reproducibility protocol
1. Verify the saved camera-to-electrode (magenta) calibration independently of the yellow ROI.
2. Use the same camera resolution, illumination, camera/chip positions, ITO spacing and fixture during each controlled trial.
3. Capture empty-with-ITO references only when **no droplet is present**. Label each separate ITO positioning session.
4. Test empty held-out placements before treating any candidate as a droplet.
5. Introduce one/two/three independently verified physical droplets on known electrode locations; record true count, position, droplet volume, ITO placement, prediction and diagnostics.
6. Compare false positives, false negatives, duplicate candidates, channel assignment and processing times; split independent sessions across evaluation.

## Known failure modes
ITO boundary artifacts may be detected when they cross active electrodes; independently moving ITO cannot always be registered by a single global image shift. Multiple references can remove genuine droplet image differences. A stable red/orange marker is **not** ground truth. Never use these unverified candidates to actuate electrodes.
